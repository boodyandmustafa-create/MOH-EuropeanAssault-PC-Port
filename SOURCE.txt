SOURCE CODE OF THE LGPL PARTS
=============================

MOHEuropeanAssault.exe contains code from the xemu project (GNU LGPL 2.1 or later), listed in NOTICE.txt. The source of
those files - exactly as they were compiled into this release, including this port's own changes - is in the
folder  source\xemu-derived\  of this package. The original project is at https://github.com/xemu-project/xemu .

Our changes to those files:
  apu_vp.c  - a guard that stops and restarts the software mix ring when it stalls (fixes sound that vanishes),
              plus extra diagnostics.
  nv2a_core.c, nv2a_regs.h, nv2a_state.h, apu_*.c/h, fpconv.h, apu.h - used as extracted by the xboxrecomp
              toolkit (https://github.com/sp00nznet/xboxrecomp, MIT, which also carries the LGPL texts).

The rest of the program is open source too: the port's own code is in the folder  source\  of the project page
(https://github.com/boodyandmustafa-create/MOH-EuropeanAssault-PC-Port/tree/main/source), under the MIT licence
(source\LICENSE-PORT.txt). The only thing not published is the recompiled game code (source\README.md explains why).
Your rights under the LGPL: you may modify the LGPL files and use your modified version in place of ours; the whole
source needed to do so is in that folder.

The full licence text is in LICENSES\LGPL-2.1.txt.
