# قائمة الصور لصفحة GitHub (خاصة بك، لا تُنشر)

الـ README الآن مبني بنظام: كل ميزة لها عنوان فرعي خاص بها وصورة واحدة تحتها مباشرة (طلبك). كل صورة لها اسم
ملف محدد بالضبط — احفظ باسمها هذا في مجلد:
```
C:\Users\nsr\Downloads\xboxrecomp-0.16.0\github_repo\media\
```
وقل لي "جاهزة" فأدفعها. (لو غيّرت اسم ملف، قل لي فقط فأعدّل الاسم في README.md ليطابق.)

ملاحظة مهمة: **لا يوجد مصدر آخر لهذه الصور سواك** — كل هذه ميزات خاصة بهذا المنفذ لا توجد في أي مكان آخر،
يجب أخذها من جلسة لعب حقيقية على جهازك.

## أداتان فقط

1. **F12** (لقطة شاشة تلقائية في `screenshots\`) — تصلح لأغلب الصور، **لكن لها نقطة عمياء**: دم/غبار/مطر
   الشاشة وقائمة Recomp Settings (F1) هي نوافذ شفافة منفصلة فوق اللعبة، F12 لا يلتقطها.
2. **OBS Studio بوضع Display Capture** (ليس Game Capture ولا Window Capture) أو ببساطة `Win+PrtScn` —
   يلتقط كل شيء بما فيه الطبقات الشفافة. استخدمه لكل ما فيه علامة ⚠ أدناه.

تحقّق سريع: شغّل `play_raintest.bat`، اضغط F12 — إذا لم تظهر قطرات المطر في الصورة المحفوظة فهذا طبيعي
(هذا بالضبط ما تحتاج OBS/PrtScn له).

## الفيديو الوحيد (Super Accuracy)

أسهل طريقة بدون رفع لأي موقع خارجي: سجّل 5-10 ثوانٍ بـ OBS (إطلاق بدون تحريك الفأرة، يظهر عدم ارتداد
السلاح)، ثم حوّله إلى GIF قصير ببرنامج **ScreenToGif** (مجاني، ويندوز) أو أي محول mp4→gif. احفظه باسم
`feature_accuracy.gif` ويظهر مباشرة في الصفحة بدون أي خطوة رفع إضافية.

(لو تفضّل فيديو حقيقي طويل بدل GIF لاحقاً، له طريقة أخرى عبر مرفقات GitHub — اسألني عند الحاجة.)

## ماذا لا تصوّر / لا تُبرز كميزة مكتملة

- **الاحتفاظ بالجثث (Keep corpses)**: مُسقطة، لا تصوّرها ولا تذكرها.
- **Damage/Range/FireRate لتعديلات الأسلحة**: غير مؤكدة، صوّر فقط MagazineSize.
- **تعديلات الأصوات (mods\sounds)**: لم تُختبر كاملة بعد.

## بعد التصوير

حوّل أي صورة كبيرة (2560x1440) إلى JPG بعرض ~1920 تقريباً قبل وضعها في `media\` حتى تفتح الصفحة بسرعة (أو
اتركها PNG إن كانت الصورة صغيرة أصلاً مثل لقطات اللانشر).
