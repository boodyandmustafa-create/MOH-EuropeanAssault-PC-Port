# Launcher options. One option per line:  tab|key|type|default|values|dep
#
#   tab     game, controls, mods, extras, recomp, saves, credits
#   key     the key written to recomp_settings.ini.  @fov and @draw are special (fov_saved.txt / draw_saved.txt).
#           Labels come from lang\en.txt / lang\ar.txt:  <key> = name,  <key>.d = description,
#           <key>.v.<value> = how a value is shown (otherwise the raw value is shown).
#   type    choice  (values = comma list; the arrows step through it)
#           toggle  (0 / 1)
#           lang    (english + every folder of languages\)
#           bind    (a key binding: default 'keys;pad buttons', key bind_<action> -> kb_/pad_ lines of the ini)
#           movekey (one movement key; keys bind_move0..3 = forward, back, left, right -> move= line)
#           action  (a button; the key names what it does, see Act() in launcher.cpp)
#           link    (a button that opens the address in "default")
#           note    (text only)
#   dep     optional 6th field: the key of another option. While that option is 0 this row is greyed out and
#           cannot be changed (the rain rows depend on "rain")
#
